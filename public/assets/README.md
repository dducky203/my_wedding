# Thư mục assets — file nhạc nền

File nhạc nền `beautiful-in-white.mp3` đã có sẵn tại đây
(đúng tên trong `config.json` → `music.url`), nhạc phát được ngay
sau khi build/deploy, không cần copy thêm.

Muốn đổi bài khác: thay file MP3 khác vào đây với cùng tên
`beautiful-in-white.mp3` rồi build lại, hoặc vào dashboard →
mục Nhạc nền → Upload file mp3 (≤ 5MB), nhạc sẽ được lưu vào
config và phát ngay mà không cần file ở đây.
